# My Time

A static clock page: the **MY TIME** analog clock on a cyan background, with a 24-hour digital clock (HH:MM) underneath, drawn in the same hand-lettered style. It works on phone and desktop. It's plain HTML, CSS and JavaScript with no build step.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The page |
| `style.css` | Layout and colors (cyan `#00ffff`, ink `#252525`, mint `#dbffd9`) |
| `clock.js` | Moves the hands and draws the digital digits |
| `music.js` | Plays `Background.mp3` on a loop at 30% volume |
| `Background.mp3` | Background music |
| `img/clock-face.png` | Clock face without hands (the hands are drawn in code) |
| `img/clock-hands.png` | Clock with hands (used as the favicon and share image) |

## Run locally

Open `index.html` in a browser. That's all you need to do.
